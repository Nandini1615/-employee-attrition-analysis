# Employee Attrition Analysis Project

## Project Overview
Analyzed why 600 employees are leaving using SQL and Power BI. Found 95 employees (15.83%) left, mainly freshers with low salary and low job satisfaction.

## Tools Used
- MySQL - Data Cleaning & Analysis
- Power BI - 2 Page Dashboard
- Excel - Dataset

## Files
- Employee_Analysis.sql - All SQL Queries
- employee_analysis_project_data.pbix - Power BI Dashboard
- cleaned_employee_analysis_project_dataset AS CSV.xlsx - Dataset

## Key Insights
1. Attrition Rate 15.83% - 95 out of 600 left
2. Freshers Leaving Most - 0 Years Experience = Highest
3. Low Salary = High Attrition - Medium Salary slab highest
4. Marketing Department Highest - 19 left
5. Male 56 left (58.95%), Female 39 left (41.05%)
6. Bachelor's Degree Highest leaving

## Business Recommendation
Increase salary for Freshers, focus on Marketing & Finance retention, improve Job Satisfaction.
